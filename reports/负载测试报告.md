# 负载测试报告

> 工具：Locust；目标：客诉舆情退赔决策系统（真实端点 `/api/v1/*`）。

## 测试环境

- 后端：FastAPI（uvicorn 多 worker ×4）+ PostgreSQL + Redis(redis-stack)
- 容器资源限制：backend 4 CPU / 2G，postgres 8 CPU / 2G，worker 4 CPU / 1G，redis 2 CPU / 1G
- 场景：A 建案 / B 查询 / C 审批 / D 大盘（见 loadtest/locustfile.py）
