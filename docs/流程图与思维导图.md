### 1.1 工作流状态机

```mermaid
stateDiagram-v2

    state reject: Reject

    execute_refund --> [*]: 退款完成
    reject --> [*]: 已拒绝
```

```mermaid
flowchart TD
```

```mermaid
    LLMDeep -->|安全| Pass

    Reject --> Audit[写入 AuditLog<br/>action: critic:rejected]
    Reject --> UpdateStatus[更新工单状态为 REJECTED]
```

## 三、关键数据流

### 3.1 工单完整生命周期

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant API as FastAPI
    participant Graph as LangGraph
    participant Agent as Agents
    participant DB as PostgreSQL
    participant Redis as Redis
    participant Sandbox as Docker 沙箱

    Client->>API: POST /api/v1/cases (创建工单)
    API->>DB: 持久化工单 (CREATED)
    API->>Redis: 投递 Refund Stream
    API-->>Client: 返回 case_id

    loop LangGraph Workflow
        Graph->>Agent: IntakeAgent
        Agent->>DB: 记录 AgentRun
        Agent->>Redis: 发布事件
        
        Graph->>Agent: EvidenceAgent
        Agent->>Sandbox: OCR 解析凭证
        Sandbox-->>Agent: 文本 + 置信度
        Agent->>DB: 持久化证据
        
        Graph->>Agent: MergedRiskAgent
        Agent->>Agent: LLM 评分 (合并)
        Agent->>DB: 持久化风险
        
        Graph->>Agent: DecisionPolicy
        Agent->>Agent: 规则引擎计算
        Agent->>DB: 更新决策结果
    end

    alt 决策 = APPROVE
        Graph->>Agent: ExecuteRefund
        Agent->>DB: 幂等退款
        DB-->>Client: SSE 推送完成
    else 决策 = REJECT
        Graph->>Agent: Reject
        DB-->>Client: SSE 推送拒绝
    else 决策 = HUMAN_REVIEW
        Graph->>Agent: HumanReview
        API->>Client: 等待人工审批
        Client->>API: POST /review (主管审批)
        Graph->>Agent: 恢复执行
    end
```
