## 采纳的初始裁决值（来自实施指南建议，经确认）

| 规则 | 值 |
|---|---|
| 金额保存方式 | 整数分（amount_cent） |
| 退款金额超过阈值 | 默认进入人工审核 |
| OCR 置信度低 | 默认进入人工审核，不自动批准 |
| 模型输出解析失败 | 重试一次，仍失败进入人工审核 |
| 审批并发冲突 | 返回 HTTP 409，不覆盖先完成决定 |
| Redis 锁 | `refund:approval:{case_id}`，短 TTL（10s），Lua 校验 token 释放 |
| 业务最终状态 | 以 PostgreSQL 为准 |
| 运行时事件 | Redis Streams + SSE 推送 |
| 外部公开舆情采集 | 不纳入 MVP |
