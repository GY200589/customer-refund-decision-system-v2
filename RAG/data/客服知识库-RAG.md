# 客服知识库（RAG 用）

> 适用系统：客诉退赔决策系统-v2
> 用途：为后期 RAG 客服机器人提供结构化知识，统一客服口径，辅助用户理解退款/退货/投诉处理规则。

---

## 一、退换货规则

### 1.1 无理由退货

| 项目 | 规则 |
|------|------|
| 退货时限 | 签收之日起 **7 日内**可申请无理由退货 |
| 退款时限 | 退货签收并验收合格后 **3 个工作日内**原路退回 |
| 适用商品 | 未穿着、未洗涤、吊牌完整、不影响二次销售的商品 |
| 不适用商品 | 内衣/泳装/袜子等贴身衣物、定制商品、已拆封的食品/化妆品、促销标注"不退不换"的商品 |
| 运费承担 | 无理由退货：用户承担退回运费；商品质量问题：商家承担双向运费 |

### 1.2 需要提供的凭证

申请退款/退货时，需至少提供以下一种凭证：

1. **商品实物照片**（商品全貌、问题部位特写、吊牌）
2. **订单截图**（含订单号、购买商品、金额、下单时间）
3. **物流凭证**（快递单号、签收记录、开箱视频/照片）
4. **质检报告或第三方鉴定**（高价值商品争议时）

> 提示：系统支持上传图片后自动 OCR 识别订单号、金额、日期等信息，识别失败可转人工复核。

### 1.3 哪些情况不退

以下情形原则上不予退款：

- 超过 7 日无理由退货期限
- 商品已穿着、洗涤、拆牌、人为损坏
- 缺少原包装、配件、吊牌
- 用户提供虚假凭证或恶意重复申请
- 用户历史退款率过高（系统风控命中，需转人工审核）
- 商品为赠品、秒杀、特价且页面已标注不退不换

### 1.4 质量问题退货

| 情形 | 处理方式 |
|------|----------|
| 商品破损/污渍/开线 | 支持退货退款，商家承担运费 |
| 发错货/漏发 | 支持退货退款或补发，商家承担运费 |
| 尺码不合但未质量问题 | 支持 7 日无理由退货，用户承担运费 |
| 与描述严重不符 | 支持退货退款，必要时平台介入 |

## 四、客服口径（FAQ）

### Q1：怎么申请退款？

> 您可以在工作台点击"新建案件"，填写订单号、退款金额、退款原因并上传凭证照片，系统会自动识别并进入审核流程。

### Q2：退款多久到账？

> 审核通过后，退款会在 **3 个工作日内**原路退回。具体到账时间以银行/支付平台为准。

### Q3：为什么我的退款被拒绝了？

> 常见原因包括：超过 7 天无理由期限、凭证不足、商品已影响二次销售、或系统检测到高风险行为。您可以在案件详情页查看具体拒绝原因，有疑问可申请人工复核。

### Q4：上传的凭证被提示 OCR 识别失败怎么办？

> 请重新拍摄清晰照片，确保订单号、金额、日期完整可见，避免反光、模糊、遮挡。如果仍识别失败，系统会自动转人工处理，您无需重复提交。

### Q5：为什么 1 分钱的小额退款也被拒绝了？

> 系统不会因为退款记录多就直接拒绝。即使金额很小，如果历史退款率很高、本次又申请接近全额，并同时出现高频申请、重复凭证等异常，才会拒绝或转人工审核。

### Q6：退款金额和实际支付金额不一样怎么办？

> 系统会比对订单真实金额，如果填写金额与订单金额偏差过大，会转人工复核。请确认您填写的金额是否正确。

### Q7：我可以批量申请退款吗？

> 主管/管理员可以使用审核中心的 Excel 批量导出/上传功能处理批量审批，普通用户请逐条提交。

### Q8：系统提示"存在注入风险"是什么意思？

> 您的投诉文本中包含疑似攻击或恶意指令内容，系统为保护平台安全已自动拦截。请用正常语言描述您的问题后重新提交。

### Q9：高风险案件为什么要转人工？

> 当系统判断证据不足、金额较大、存在安全疑似或用户画像异常时，会转人工客服复核，确保每一笔退款都审慎处理。

### Q10：人工审核要多久？

> 人工审核一般在 **1-2 个工作日**内完成。超时未处理的案件会自动升级标记，避免遗漏。

## 五、常见售后问题及解决办法

> 面向大众用户的日常售后咨询，客服/机器人可直接按以下口径回复。

### 5.1 商品质量问题

#### 问题：衣服洗后缩水/掉色严重

**解决办法**：
- 确认商品洗涤方式是否按水洗标执行（水温、是否可机洗、是否可漂白）
- 若首次洗涤即严重缩水/掉色，且洗涤方式正确，支持退货退款
- 轻微浮色/正常缩水（<3%）属于行业正常范围，不在售后范围

**客服口径**：
> "亲，衣服首次清洗轻微浮色/缩水属于正常现象。如果掉色严重或缩水超过正常范围，请提供洗涤后的照片和订单截图，我们核实后为您处理。"

#### 问题：商品有异味

**解决办法**：
- 建议先通风晾晒 1-2 天，多数新衣服异味会自然消散
- 若晾晒后仍有刺鼻异味，可能是染色/印染残留，可申请退货退款
- 需提供商品照片和异味情况说明

**客服口径**：
> "新衣服有轻微味道是正常的，建议您先通风晾晒。如果味道刺鼻且不散，请拍照并联系我们，我们会为您安排退货。"

#### 问题：收到的商品破损/有污渍

**解决办法**：
- 签收时当面验货最好，签收后 24 小时内提供照片仍可处理
- 提供商品问题照片 + 快递外包装照片
- 确认属物流破损则联系快递理赔；属发货问题则商家补发或退款

**客服口径**：
> "非常抱歉给您带来不好的体验。请您提供商品问题部位照片和快递外包装照片，我们核实后会在 24 小时内给您处理方案。"

#### 问题：线头多/做工粗糙

**解决办法**：
- 轻微线头属于正常工艺，不影响穿着，可赠送小额补偿或优惠券
- 严重开线、破洞、左右不对称等工艺问题，支持退货退款
- 以照片为依据判定

**客服口径**：
> "亲，少量线头属于正常现象。如果确实存在开线、破洞等严重工艺问题，请拍照发给我们，我们支持退货退款。"

### 5.2 物流问题

#### 问题：物流显示已签收但我没收到货

**解决办法**：
- 先确认是否家人/同事/物业/驿站代收
- 联系快递员核实签收人和签收地点
- 若确实未收到，发起物流工单查询；确认丢件则补发或退款

**客服口径**：
> "请您先确认家人、同事、物业或快递驿站是否代收了。如果都没有，我们会联系快递核实。若确认丢件，您可以选择补发或全额退款。"

#### 问题：快递一直在运输中/卡住了

**解决办法**：
- 查看是否遇到节假日、大促、疫情/天气等不可抗力
- 超过预计到达时间 3 天仍无更新，联系快递公司催件
- 超过 7 天未动，可申请退款或补发

**客服口径**：
> "物流受大促/天气影响可能略有延迟。如果超过预计时间 3 天还没更新，我们会帮您联系快递催件；超过 7 天未动，您可申请退款或补发。"

#### 问题：地址填错了还能改吗？

**解决办法**：
- 未发货：直接修改收货地址
- 已发货：联系快递尝试改地址，可能产生改派费用
- 已签收：无法改地址，需自行联系快递员或驿站转寄

**客服口径**：
> "如果您的订单还没发货，可以直接修改地址。如果已经发货，我们会尽力帮您联系快递改地址，但可能需要您承担改派费用。"

#### 问题：快递显示拒收/退回怎么办？

**解决办法**：
- 联系快递员了解拒收原因（地址不详、联系不上、用户主动拒收等）
- 商家收到退回商品后安排退款或补发
- 因用户原因拒收（不想要了），退回运费由用户承担

**客服口径**：
> "您的快递显示拒收/退回，我们会先联系快递确认原因。商品退回仓库后会为您安排退款或补发。如因您个人原因拒收，退回运费可能需要您承担。"

### 5.3 发错/漏发问题

#### 问题：收到的颜色和尺码不对

**解决办法**：
- 提供订单截图、收到的商品照片、快递单号
- 确认发错后，支持退货退款或换货，商家承担来回运费
- 可先发新货，用户收到后再寄回错发商品

**客服口径**：
> "非常抱歉发错货了。请您提供商品照片和订单截图，我们核实后给您换货或退款，来回运费都由我们承担。"

#### 问题：少发了配件/赠品

**解决办法**：
- 提供开箱视频或照片，证明收到包裹时即缺少
- 确认漏发后补发，或按价值折算退款/补偿

**客服口径**：
> "请您提供包裹开箱照片或视频，确认漏发后我们会第一时间给您补发，或者按价值折算补偿。"

### 5.4 价格与优惠问题

#### 问题：刚买完就降价了，能退差价吗？

**解决办法**：
- 本店支持 **7 天价保**：签收后 7 天内，商品降价可申请退差价
- 差价以实际支付金额和当前活动价计算
- 秒杀、限量、优惠券等特殊活动商品不参与价保

**客服口径**：
> "亲，我们支持 7 天价保。如果您签收后 7 天内商品降价了，可以申请退差价。请提供当前价格截图和订单截图。"

#### 问题：优惠券/满减没用上怎么办？

**解决办法**：
- 订单未付款：取消重下即可
- 订单已付款但未发货：可申请取消后重新下单
- 订单已发货/已签收：优惠券已使用，无法补差

**客服口径**：
> "如果订单还没付款，您取消重下就可以用券。如果已经发货了，优惠券就无法再补用了，下次下单前记得勾选哦。"

#### 问题：发票怎么开？

**解决办法**：
- 确认收货后可申请开具电子发票
- 发票内容一般为"服装"或"服饰"，按订单实际金额开具
- 发票抬头、税号在订单详情页填写或联系客服登记
- 电子发票一般 3-5 个工作日内发送至预留邮箱

**客服口径**：
> "确认收货后可以申请电子发票。您可以在订单详情页填写发票信息，或者把抬头和税号发给我，我们 3-5 个工作日内开具。"

### 5.5 账号与投诉

#### 问题：登录不上/忘记密码

**解决办法**：
- 使用手机号/邮箱 + 验证码登录
- 在登录页点击"忘记密码"重置
- 若账号被冻结，联系客服/管理员核实原因

**客服口径**：
> "您可以尝试用手机号验证码登录，或者点击忘记密码重置。如果提示账号被冻结，请把账号发给我，我帮您查询。"

#### 问题：对处理结果不满意，怎么投诉？

**解决办法**：
- 先联系原处理客服说明不满原因
- 可申请主管复核，案件会升级处理
- 仍无法达成一致，可提交平台仲裁或消费者协会

**客服口径**：
> "如果您对处理结果不满意，可以申请主管复核，我们会重新审核您的案件。如仍有争议，也可以走平台仲裁渠道。"

### 5.6 其他高频问题

#### 问题：可以取消订单吗？

**解决办法**：
- 未发货：可直接取消，款项原路退回
- 已发货：需等签收后申请退货退款，或联系快递拒收
- 定制/预售商品：按商品规则处理

**客服口径**：
> "如果订单还没发货，可以直接取消。如果已经发货了，您签收后可以申请 7 天无理由退货，或者拒收退回。"

#### 问题：退款退到哪里？

**解决办法**：
- 原路退回原支付账户
- 微信/支付宝/银行卡均可原路退回
- 退回时间以支付平台处理为准

**客服口径**：
> "退款会原路退回您的支付账户。微信/支付宝一般是即时到账，银行卡可能需要 1-3 个工作日。"

## 六、OCR 识别失败的补充材料规则

### 6.1 识别失败常见原因

1. 图片模糊、反光、裁剪不全
2. 凭证缺少关键字段（订单号、金额、日期）
3. 手写单据、非标准格式
4. 图片格式异常或文件损坏
5. 多张凭证叠加导致识别混乱

### 6.2 补充材料要求

当 OCR 识别失败时，客服可引导用户补充以下材料之一：

| 补充材料 | 要求 |
|---------|------|
| 重新拍摄凭证 | 光线充足、文字清晰、四边完整、不反光 |
| 订单详情截图 | 从购买平台截取，包含订单号、商品、金额、时间 |
| 支付记录截图 | 支付宝/微信/银行卡交易记录，包含交易单号 |
| 物流签收证明 | 快递签收底单或驿站取件记录 |
| 开箱视频 | 从拆快递开始连续拍摄，展示商品问题 |

### 6.3 处理流程

```
OCR 识别失败 → 系统提示"凭证存疑" → 案件转人工复核
                          ↓
           客服联系用户补充材料 → 重新上传 → 再次识别
                          ↓
           补充后仍无法识别 → 人工根据经验判定 → 给出决策建议
```

## 七、高风险转人工的通俗解释

### 7.1 什么情况会转人工？

以下情况系统不会自动退款，会交给人工客服复核：

- 退款金额较大（如超过 300 元）
- 缺少有效凭证或 OCR 识别置信度低
- 用户历史退款率较高，且本次又申请高比例退款或出现其他异常
- 欺诈分或舆情风险评分较高
- 投诉文本触发安全规则（如疑似注入攻击）
- 订单信息无法核实或与填写信息严重不符
- OCR 人工修正后仍需二次确认

### 7.2 怎么跟用户解释

- "您的申请需要人工客服进一步核实，请耐心等待 1-2 个工作日。"
- "由于您申请的金额较大/凭证需补充/订单信息需要核实，系统已自动转人工复核。"
- "为了保护平台和您的权益，部分高风险申请会由人工客服最终确认，感谢您的理解。"
- "您的历史退款率和本次申请比例同时偏高，本次申请已转人工审核，我们会尽快为您处理。"

### 7.3 人工审核后可能的结果

| 结果 | 说明 |
|------|------|
| 批准退款 | 证据充分，符合退款规则 |
| 驳回申请 | 证据不足或不符合退款条件 |
| 要求补充材料 | 需要用户提供更多凭证 |
| 升级处理 | 复杂争议，需要主管或法务介入 |

## 九、智能客服查询与店铺基本信息

### 9.1 商品搜索与推荐口径

- 商品搜索必须以当前启用的商品主数据为准，不能凭空编造名称、价格、颜色、尺码、面料或库存。
- 用户可以组合颜色、类别、面料和版型搜索，例如“灰色连帽拉链卫衣、重磅棉、宽松版型”。
- “黑色的裤子”表示同时筛选黑色和下装裤类；“灰色”可匹配灰色、浅灰、深灰等同色系，但结果必须展示商品实际标注颜色。
- 推荐结果应展示商品名、实际颜色、面料/版型、价格和站内详情链接。没有完全匹配项时必须明确说明，并提示用户补充条件。
- 商品分类、价格和展示图片来自商品主数据；知识库只保存搜索口径，不保存容易过期的商品价格。

### 9.2 订单号查询口径

- 订单号以 `SO` 开头，后接日期时间和字母数字校验码。输入完整订单号时，只查询当前登录用户本人的订单。
- 查到订单后展示：订单号、支付状态、订单状态、实付金额和商品，并提供该订单的站内详情链接。
- “订单详情 + 订单号”必须打开普通订单详情，不能因为订单曾申请退款就自动跳到退款详情。
- 查不到时统一回复“没有查到该订单，请核对订单号”，不得返回其他用户的订单信息，也不得暗示他人的订单是否存在。

### 9.3 退款详情查询口径

- 用户说“退款进度、退款状态、退款详情、退款案件”时进入退款查询，不得误判为新建退款。
- 输入订单号查询退款时，只返回该订单关联、且属于当前登录用户的退款案件，并提供退款详情链接。
- 输入案件号时精确查询该案件。退款详情应展示退款金额、商品、处理状态、时间节点和凭证信息。
- 订单存在但尚未申请退款时，要明确区分“订单可以查到”和“没有退款记录”，并引导查看订单或发起退款。
