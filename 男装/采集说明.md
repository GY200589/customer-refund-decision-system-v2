# 男装图片与商品数据采集说明

生成时间：2026/9/3 13:09:56

## 这批数据做什么

这是一套给客诉退赔决策系统做商品视觉识别演示和验收用的男装小数据集。每一行对应一个 SKU，图片文件名和商品数据一一对应。核心商品字段已按模板排列：商品名、一级分类、二级分类、颜色、尺码、价格（元）、面料/版型、一句话；下装额外保留长度字段用于短裤/七分裤验收。

## 真实数据和演示数据

- 真实采集：淘宝搜索页动态抓取的原始商品标题、搜索页价格、商品主图、商品 ID 和来源链接。
- 演示补齐：搜索卡片没有稳定提供的颜色、尺码、面料/版型，以及规范化商品名和一句话描述，已按图片和标题补齐，并在“数据性质”列统一标记为“演示商品”。
- 这样做是为了让页面、视觉识别和 RAG 演示能直接运行；正式上线前应从商家商品详情或 ERP 主数据替换这些补齐字段。

## 来源和合规说明

- 主要来源：用户提供的淘宝男装搜索页，以及为补齐羽绒服、短裤、七分裤、西裤、运动裤而追加的同站搜索页。
- 本次通过 Chrome 动态页面采集商品标题、价格和主图，再下载到本地；不是调用淘宝开放平台接口。
- 图片和商品信息仅用于内部演示、人工标注和模型验收，不用于公开销售或商业再分发。

## 混淆对覆盖

- 牛仔裤 vs 休闲长裤：丹宁牛仔、非丹宁日常长裤均有样本。
- 运动裤 vs 工装裤：束脚/针织面料和多口袋/厚棉布均有样本。
- 短裤 vs 七分裤：二级分类按规则归入“短裤”或相应裤类，长度列分别标记“短裤/七分”。

## 使用方法

1. 页面展示时读取“图片相对路径”列。
2. 视觉模型识别结果与“一级分类、二级分类、长度、颜色”对答案，统计准确率和混淆矩阵。
3. 不要用文件名猜分类；商品数据表中的人工标签才是标准答案。
4. 约 20% 的图片建议另存为独立验收集，评测时打乱顺序，避免模型只记住文件名。
